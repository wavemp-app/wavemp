# WaveMP

[WaveMP](https://github.com/wavemp-app/wavemp) is a nostalgic media player for your self-hosted music and music videos.

Select the folder or dataset with your music and music videos as media storage. The user of WaveMP
(`568` by default) needs read access to it, and write access to edit tags from within WaveMP.
See the [WaveMP documentation](https://github.com/wavemp-app/wavemp#readme) for all settings.
